⚙ My homemade Instantly

How my cold email machine works.

I built my own version of Instantly. Here is exactly how it runs, step by step.

1Get the leads

We pull leads automatically

We have a system running that gets us leads on its own.
It scrapes Google Maps for the businesses we want. Then it runs each one through AnyMailFinder to get the decision-maker's real email and their LinkedIn.
  • Scrapes Google Maps for our target businesses
  • Runs each one through AnyMailFinder
  • Gets the decision-maker's real email
  • Plus their LinkedIn profile
owner@business.com · found
2Sort it and write

A worker sorts it, Claude writes

A worker pulls all that lead data from step 1 and sorts it.
Then Claude takes over. Haiku writes the outbound email, and Sonnet writes the reply when the lead writes back. Both run through OpenRouter.
  • Worker pulls and sorts all the lead data
  • Haiku writes the outbound email
  • Sonnet writes the reply when they respond
  • Both powered by Claude, via OpenRouter

Haiku writes · Sonnet replies · via OpenRouter
3Send it the right way

Spread across 12 inboxes

The emails go out across 12 inboxes, never from just one.
The system rotates evenly between them, with guardrails built in so we never email the same person twice and never double-send. Every inbox has a daily limit so none gets overused.
  • Spread across 12 inboxes, not one
  • Rotates evenly between them
  • Never emails the same person twice
  • A daily cap on every inbox

4Make sure it lands

Built to land in the inbox

Everything is set up so the emails land in the inbox, not spam.
The inboxes are warmed up first. The sending is paced like a real person typing, with random spacing between every email so it never looks like a blast.
  • Inboxes warmed up before any sending
  • Paced like a real person, not a machine
  • Random spacing between every send
  • Built to land in the primary inbox
✓ lands in primary inbox
5Handle the replies

An AI agent replies for us

When a lead writes back, the system reads it and figures out what they want.
If they are interested, our AI agent writes and sends the auto-reply for us. Anything sensitive goes to a human. The whole thing runs on its own, 8am to 5pm on weekdays.
  • Reads and filters every reply
  • AI agent sends the auto-reply for us
  • Anything sensitive goes to a human
  • Runs 8am to 5pm, weekdays
